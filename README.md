# UK Accidents Analysis
## A SQL analysis of accidents in the UK in 2015.
This project is a step by step analysis of the accidents reported in the UK. It entails the dataset, EDA process, SQL script of the codes, visualizations and a comprehensive report of the analysis.

## Software requirements
* Accidents_2015.csv is the raw provided dataset
* accidents_v2.csv is the cleaned analyzed dataset
* Use MySQL to effectively run the sql codes
* For interactive visualizations use Tableau
